## 🇬🇧 About Me
I build advanced **R packages** for time-series and panel-data econometrics — focusing on **cointegration analysis**, **quantile regression**, and porting well-known **Stata** modules into open-source R tools for the research community.

## 🇸🇦 نبذة عني
أعمل على تطوير حزم **R** متقدمة لتحليل السلاسل الزمنية والبيانات البانلية، مع التركيز على **التكامل المشترك (Cointegration)** و**الانحدار الكمّي (Quantile Regression)**، وتحويل أدوات **Stata** الشهيرة إلى بيئة R مفتوحة المصدر لخدمة الباحثين.
