## 🇬🇧 About Me
I build advanced **R packages** for time-series and panel-data econometrics with a focus on **cointegration analysis**, **quantile regression**, unit root testing and panel methods, with every method checked against its source paper.

## 🇸🇦 نبذة عني
أعمل على تطوير حزم **R** متقدمة لتحليل السلاسل الزمنية والبيانات البانلية، مع التركيز على **التكامل المشترك (Cointegration)** و**الانحدار الكمّي (Quantile Regression)**، واختبارات جذر الوحدة وأساليب البيانات البانلية، مع مطابقة كل طريقة بورقتها الأصلية.
